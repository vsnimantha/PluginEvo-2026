Weighted Selection Algorithm Explained
====================================

1. What Does This Do?
---------------------
Chooses between options (like variable names/data types) while:
- Giving rarely-used options higher chances
- Preventing the same choices repeating too often
- Keeping some randomness

2. Cookie Jar Example
---------------------
Imagine 3 cookie jars:

Jar A: Chosen 10 times before
Jar B: Chosen 2 times
Jar C: Never chosen (0 times)

Normal random pick: 
Each has 33% chance (unfair to Jar C)

Our smart method:
Jar C > Jar B > Jar A chance

3. How It Works
---------------
For each option:
1. Calculate its WEIGHT:
   weight = 1 / (times_chosen + 1)

2. Convert to PROBABILITY:
   probability = weight / sum_of_all_weights

4. Step-by-Step Calculation
---------------------------
| Option | Times Chosen | Weight Calculation | Weight | Probability |
|--------|--------------|---------------------|--------|-------------|
| A      | 10           | 1/(10+1) = 1/11     | 0.09   | ~12%        |
| B      | 2            | 1/(2+1) = 1/3       | 0.33   | ~23%        |
| C      | 0            | 1/(0+1) = 1         | 1.00   | ~65%        |

Total Weights = 0.09 + 0.33 + 1.00 = 1.42

Final Probabilities:
- A: 0.09/1.42 ≈ 12%
- B: 0.33/1.42 ≈ 23%
- C: 1.00/1.42 ≈ 65%

The two techniques combined:
- Weighted Random Sampling: Ensures probabilistic selection based on predefined weights.
- Dynamic Weight Adjustment: Adaptively updates weights based on selection history to balance fairness or exploration.

5. Why "+1" Matters
-------------------
- Prevents errors when dividing by zero
- Gives new options a starting chance
- Controls how fast probabilities change

6. Code Generation Example
-------------------------
Choosing between ["int", "float", "string"]:
- "int" used 5 times before
- "float" used 2 times
- "string" never used

Next pick probabilities:
string (0 uses) ###############
float (2 uses)  #####
int (5 uses)    ##

7. Python Code
--------------
def select_option(options, usage_counts):
    # Calculate weights
    weights = [1/(usage_counts.get(o, 0) + 1) for o in options]
    
    # Convert to probabilities
    total = sum(weights)
    probabilities = [w/total for w in weights]
    
    # Make selection
    return random.choices(options, weights=probabilities)[0]

8. Key Properties
----------------
✓ Self-balancing: Often-chosen options get lower chances
✓ Fair: Everything gets a turn eventually
✓ Adaptive: Automatically adjusts as you generate more code

9. Real-World Comparisons
------------------------
Like a teacher who:
- Calls on quiet students more often
- Doesn't ignore active students completely
- Makes sure everyone participates

10. Visual Cheatsheet
--------------------
When choosing between options:
1. Count how many times each was used before
2. Add 1 to each count
3. Take 1 divided by that number → weight
4. Divide all weights by their total → probabilities
5. Pick randomly using those probabilities

Note: This is called the "smoothed inverse frequency" method.
